# 2026-10-11 简洁风格与首页表达优化

## 需求与设计选择

用户在上一轮博客改版后提出：访客是否能一眼认识作者、了解文章与想法；随后要求突出简洁特点，并可参考现成 UI / 前端美化 skill 优化应用。

本轮读取并参考 Anthropic 官方 [frontend-design skill](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md)，采用更少装饰、真实文字和清楚的阅读顺序。没有安装外部 skill 或运行其附带代码；只采用设计指导。先更新 DESIGN.md 再实现，沿用 Python 静态生成器。

保留纸色、宋体、墨色与朱砂印章；首页改为最大 840px 单列，移除大月背景、纸纹、挂轴、重复题名、上方小标签和按钮组。主句“我是半開。”配两句说明测试背景、AI 应用与工具方向，以及开发、学习、选择和验证这些写作主题。首屏直接展示一篇真实最新文章；无文章时不产生空入口。

三项精选产品保持顺序，名称通向介绍，“打开”独立直达产品；首页不显示编号或重复在线状态。短说明保留登录、快照、本机模型边界；桌面名称与说明同行，手机上下排列。完整产品目录仍展示全部项目与公开状态，文章详情保留目录和关联阅读。完整首页区块仍遵守产品在前、文章在后。

中文与英文同步优化。英文首页标题采用既有西文书籍字体栈，文字不再拆成短语块，避免单词间距丢失。分享图同步更新，页脚保留“花看半开，酒饮微醉”。
