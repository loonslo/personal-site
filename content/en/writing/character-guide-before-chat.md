Starting a character can be harder than describing one. Appearance, personality and background all matter, but which comes first?

[Character Cards](/en/projects/character/) currently offers five steps: purpose, direction, character, scene and confirmation. A text summary updates alongside the choices, and undecided details can remain blank.

Choices provide a starting point, but also constrain expression. The creator still needs to review, extend and revise the result.

The online version copies character text and an image prompt. It does not generate images or offer text AI. Optional local model features are a separate path. A prompt is not evidence of a satisfactory finished image; results in third-party image tools remain unverified.

Where creators hesitate, and which choices they rewrite, are useful questions for future observation. They are not findings from an existing user study.
